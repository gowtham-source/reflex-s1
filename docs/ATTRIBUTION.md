# Attribution and provenance

The new implementation was authored for this project; no source code was copied from Open-Jev, Laya, SemIf or the MoR repository. Research links and inspected revisions are in RESEARCH.md.

Pretrained encoder: sentence-transformers/all-MiniLM-L6-v2, revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`, Apache-2.0 model-card metadata. The original model card is retained in `base/README.md`. This model is fine-tuned here; it is not trained from random initialization.

BANKING77: PolyAI's task-specific-datasets, revision `57ec275d8078af65b7731c2a98be812d844a6d6b`. Attribution 4.0 International license is retained in `docs/licenses/banking77.txt`. Source: https://github.com/PolyAI-LDN/task-specific-datasets. Data have been deduplicated, label descriptions normalized, converted to soft-target vectors, and the training split subdivided for validation and calibration.

CLINC150/OOS: Larson et al., “An Evaluation Dataset for Intent Classification and Out-of-Scope Prediction,” EMNLP 2019; `clinc/oos-eval` revision `828f8093932c8fe6ca7936c3d2e52903b1c523de`. Attribution 3.0 Unported license is retained in `docs/licenses/clinc150.txt`. Source: https://github.com/clinc/oos-eval. Data have been deduplicated, labels normalized, OOS incorporated as a 151st class, and the original validation split divided for validation/calibration.

Original synthetic controls: generated by `scripts/prepare.py` for this project. These are new constructed examples, not human observations or third-party benchmark records. All text/source-file hashes and resulting split counts are in `data/manifest.json`.

Model/data copyrights and licenses remain their respective owners'. Project-local weights include the pretrained encoder and its fine-tuning updates. No external model upload or publication was performed.

Open-Jev silent-failure-control-v1: Zefan Cai/Open-Jev, dataset revision `c67699e13d0ae25e35b77165a4b6b079bedc8aba`, https://huggingface.co/datasets/ZefanCai/Open-Jev. Original generated data are marked CC0-1.0. Original LICENSE-DATA and THIRD_PARTY_NOTICES are retained under `data/openjev/`; upstream exceptions are not relicensed by this project. Conversion excludes metadata from model inputs, preserves soft targets and source split/group identities, and explicitly rejects overlength records. Only the silent-failure configuration was added to the trained mixture.

SNLI: Bowman, Angeli, Potts and Manning (2015), “A large annotated corpus for learning natural language inference.” Source https://nlp.stanford.edu/projects/snli/. Dataset is CC-BY-SA-4.0; the archive README/license material is retained under `docs/licenses/`. This project converts premise/hypothesis pairs to typed decisions, subsamples by image group, removes overlap and divides the original development partition into validation/calibration. The adapted SNLI data retain their source license. Exact archive SHA-256 and conversion counts are in `data/general-manifest.json`.

Laya comparison: public weights and repository source are retained only as a baseline, under their upstream Apache-2.0 license. SemIf authored144 is retained as an external evaluation fixture, with the repository's MIT license at `baselines/SEMIF-LICENSE`. No SemIf labels are used for gradient updates.

The larger experimental encoder is `cross-encoder/nli-MiniLM2-L6-H768`, revision `b95119ce93d3e065de6214e38cd4a97b0f2f2c6d`, under Apache-2.0 model-card metadata. Its source card is retained in `base-nli/README.md`. It was previously trained on SNLI/MultiNLI and distilled from RoBERTa-Large; this project replaces its native classifier with the recursive sparse-expert decision head. These upstream training differences are disclosed in comparisons.

## Frozen external broad benchmarks

BFCL raw questions/answers use the pinned Gorilla repository revision recorded in `data/external/manifest.json`; the repository Apache-2.0 license is retained as `bfcl-license.txt`. Our function-identity projection is an adaptation, not the official benchmark evaluator. Source: https://github.com/ShishirPatil/gorilla/tree/main/berkeley-function-call-leaderboard.

BoolQ validation comes from `google/boolq` at the manifest revision, with its original model/data card saved as `boolq-card.md`. The card specifies CC-BY-SA-3.0. Credit Christopher Clark, Kenton Lee, Ming-Wei Chang, Tom Kwiatkowski, Michael Collins and Kristina Toutanova (NAACL 2019). The subset/JSON conversion retains those terms; model code licensing does not relicense dataset text. Source: https://github.com/google-research-datasets/boolean-questions.
